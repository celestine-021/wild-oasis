# The Wild Oasis

A small, responsive hotel-booking demo built with React and Vite. Guests can browse cabins, filter stays by dates and guest count, create an account, and make or cancel reservations. The admin dashboard can review and update bookings and add or remove stays.

## Run locally

```sh
npm install
npm run dev
```

## Demo data

This frontend-only demo saves accounts, bookings, room changes, and the active session in the browser's `localStorage`. It does not provide production authentication, a shared database, or server-side booking protection. Use a backend with secure password handling and reservation validation before deploying it for real guests.
